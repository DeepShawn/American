# 不被封的一天

回合制生存 / 策略解谜 / 黑色幽默。单文件网页小游戏，一局 3–8 分钟。

> 你是一个身处“不支持地区”的普通用户，每一天的目标只有一个——在 A记 的 Claude 风控眼皮底下，用完今天的对话额度，并且号还活着。

> 卡关了？看 [通关攻略](攻略.md)（全文剧透，含所有隐藏数值）。

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无外部依赖。

电脑、平板、手机浏览器都能玩：手机竖屏和横屏会切换成全屏窗口 + 底部 Dock 的布局，适配刘海和底部手势条、地址栏伸缩和弹出键盘，输入框不会触发 iOS 自动放大，也不会误触下拉刷新。

### 网页版：GitHub Pages

`.github/workflows/pages.yml` 在默认分支上 `index.html` 变动时自动发布。

首次使用需要在仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**，然后在 Actions 里重跑一次该工作流。发布地址：`https://deepshawn.github.io/American/`

### 安卓版（arm64-v8a）

`android/` 是一个原生安卓工程（Java + 系统 WebView，零第三方依赖、不申请网络权限（只用到震动）、离线可玩）。构建时会把根目录的 `index.html` 打进 APK，网页版和安卓版始终是同一份游戏。

- **下载**：每次推送后，在 Actions → *Build Android APK (arm64-v8a)* 的运行结果里下载 `bubeifeng-arm64-v8a`；推送 `v*` 标签（如 `v1.0.0`），或手动运行该工作流并填写 `release_tag`，会创建 Release 并附上 APK。
- **本地构建**：需要 JDK 17 与 Android SDK（API 35）。
  ```sh
  cd android
  ./gradlew assembleRelease   # 产物：app/build/outputs/apk/release/app-release.apk
  ```
- **签名**：默认使用 debug 签名（每次 CI 构建签名不同，覆盖安装前需先卸载旧版）。要固定签名，在仓库 Secrets 中配置 `KEYSTORE_BASE64`（`base64 -w0 release.jks`）、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`。
- 最低支持 Android 8.0（API 26），`abiFilters` 限定为 `arm64-v8a`。

## 界面

整局游戏发生在一台模拟电脑上：开机 → 锁屏 → 桌面（菜单栏、Dock、可拖动的窗口；手机上窗口全屏、Dock 在底部）。

- **群聊**：互助群里的消息一条条“正在输入”后冒出来。真消息和谣言混在一起。
- **系统设置**：关卡 1 的环境配置。网络与 VPN、日期与时间、键盘与输入法、语言与地区、浏览器、钱包、健康、蓝牙；改动会实时反映到菜单栏（输入法指示、VPN 状态、按系统时区走的时钟）。登录后锁定。
- **浏览器**：登录时逐项“验证你的环境”，然后在聊天页里完成任务。你的消息会被逐字打进输入框，Claude 先“思考”再流式输出——语气越差，想得越久。
- **突发事件**出现在它现实中会出现的地方：妈妈的微信视频和外卖电话从手机弹出来响铃，VPN 断开、手机号验证是系统弹窗，账号异常是一封邮件，Claude 的追问带着快捷回复出现在对话里。
- **邮件**：封号通知、申诉表单和判官的回信都在这里。
- **终端**：可以输入命令（`help`、`neofetch`、`ping 判官`、`sudo unban`、`traceroute claude`、`history`……）。
- 桌面上还有《生存指南.txt》、一个打不开的《另一个选项.dmg》和回收站。
- 失败是蓝屏，“不玩了”是关机。声音全部现场合成（菜单栏可静音），手机上来电和封号会震动。

## 玩法

- **账号跨天延续**：一个号活多少天就玩多少天。伪装值没回满的部分会变成判官的“印象”，扣在第二天的初始伪装值上；号越老，判官越严（规则数 3 → 4 → 5，第 4 天起白天会“更新使用政策”多开一条规则，第 7 天起所有检查加严）。号被封且申诉失败，才需要注册新号。
- **伪装值**：隐形，从 100（减去印象）开始，归零即封号。游戏不会告诉你哪一步扣了分，只能从 Claude 的语气反推：
  “当然可以！” → “好的，我来帮你。” → “我理解你的需求。” → “……你其实可以用中文的。”
- **16 条隐藏规则**：时区罪、输入法残留、温水嫌疑、设备连坐、错别字侧写、申诉自证、超前封禁、虐待模型、作息侧写、字体指纹、节点连坐、邮编侧写、礼貌过度、复制粘贴、乡愁侧写、浏览器语言。每个“稳妥”选项都有固定代价，全选稳妥活不下来——必须推理今天开了哪几条，然后赌。
- **情报**：
  - 登录前的**互助群**：真消息和谣言混在一起，“老哥（存活 213 天）”比“萌新（存活 0 天）”靠谱，截图哥来源不明。
  - 对话中的**试探判官**：Claude 的回答一定暗示一条真实规则，但浪费一条额度。
  - 每天结束时**猜规则**：猜对越多，判官对你的印象越淡。
- **关卡 1 登录**：节点地区、节点类型、时区、登录时间、输入法、系统字体、浏览器语言、支付与账单地址、昨晚喝了什么、设备记录。注意互相矛盾的组合；过于完美的配置本身也可疑。
- **关卡 2 对话**：在浏览器里和 Claude 聊。6 种话题（写邮件、改代码、问知识、写求职信、练英语、规划行程），每段对话都能连着聊七八轮，每轮从“说什么”里选一句接得上的话，再选语言、标点、语气、长度、方式。左边是对话列表，随时可以开新对话、来回切换。额度免费 8 条 / 付费 14 条；做完一件事后可以接着聊、开新话题，或者按“下线”收工——多做一件事判官的印象会淡一点，但聊得越久，判官看得越仔细。途中会随机撞上 11 种突发事件（妈妈的微信视频、节点掉线、手机号验证、Claude 突然说中文……），每个选项都是取舍。
- **关卡 3 申诉**：最多 3 次，同一个号申诉越多越难；成功的号会被判官长期记住。“申诉入口”可能把你带去 Claude Code 网页端再带回来。
- **结算**：完成任务——“恭喜。你今天没有被封。但你明天还会来吗？”；额度用完但没做完——号活着但不算赢；封号——随机一条社区地狱笑话 + “再来一次”。连续失败 7 天解锁隐藏结局。

进度、成就、连败天数保存在本浏览器的 localStorage 中（无痕模式下也能玩，只是不保存）。
