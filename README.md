# 不被封的一天

回合制生存 / 策略解谜 / 黑色幽默。单文件网页小游戏，一局 3–8 分钟。

> 你是一个身处“不支持地区”的普通用户，每一天的目标只有一个——在 A记 的 Claude 风控眼皮底下，用完今天的对话额度，并且号还活着。

## 运行

直接用浏览器打开 `index.html` 即可，无需构建、无外部依赖。手机宽度可玩。

## 玩法

- **伪装值**：隐形，从 100 开始，归零即封号。只能从 Claude 的语气反推：
  “当然可以！” → “好的，我来帮你。” → “我理解你的需求。” → “……你其实可以用中文的。”
- **隐藏规则**：每局从 8 条封号理由（时区罪、输入法残留、温水嫌疑、设备连坐、错别字侧写、申诉自证、超前封禁、虐待模型）中随机启用 3 条，结算时揭晓。
- **关卡 1 登录**：节点、时区、输入法、Wi-Fi、支付方式、昨晚喝了什么、设备记录。注意互相矛盾的组合；过于完美的配置本身也可疑。付费额度 6，免费额度 4。
- **关卡 2 对话**：每轮选语言、标点、长度、姿态。长段落和九宫格速打能多消耗额度（更快通关），但有代价；“表演外国人”能回一点伪装值，演多了反被识破。判官每轮的例行审查会越来越严。
- **关卡 3 申诉**：最多 3 次，基础成功率略高于真实的 10.6%；不同话术和证件有加成，也可能进入“再审”。“申诉入口”链接可能把你带去 Claude Code 网页端再带回来。
- **结算**：存活则“恭喜。你今天没有被封。但你明天还会来吗？”；失败则随机一条社区地狱笑话 + “再来一次”。连续失败 7 天解锁隐藏结局。

进度、成就、连败天数保存在本浏览器的 localStorage 中（无痕模式下也能玩，只是不保存）。
